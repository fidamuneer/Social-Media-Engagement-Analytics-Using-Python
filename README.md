# Social-Media-Engagement-Analytics-Using-Python

## Project Overview

This project focuses on analyzing social media engagement data using Python. The goal is to explore audience behavior, understand content performance, identify engagement patterns, and discover meaningful insights through data analysis and visualization.

## Objectives

- Clean and prepare the dataset for analysis.
- Perform Exploratory Data Analysis (EDA).
- Analyze engagement across content types, categories, countries, age groups, devices, and sentiments.
- Create visualizations to identify patterns and trends.
- Extract meaningful insights from the data.

## Tools & Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Jupyter Notebook

## Project Workflow

1. Data loading and inspection
2. Data cleaning and preprocessing
3. Exploratory Data Analysis (EDA)
4. Data wrangling and feature creation
5. Statistical analysis
6. Data visualization
7. Insight generation

## Key Insights

- Video posts recorded the highest average engagement, while reels had the lowest.
- Food content recorded the highest average engagement rate.
- Users aged 41–60 showed higher engagement, while users above 60 showed the lowest.
- Mobile users recorded the highest average watch time.
- Most posts had low engagement rates, with a few unusually high values.
- Impressions showed a weak negative correlation with engagement rate (-0.23), while likes showed a very weak positive correlation .
